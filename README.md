# Mathsy Meet 🎥 📐

A standalone, commercial-ready Google Meet clone with **collaborative mathematical geometry tools, live quizzes & polls, and enterprise Mediasoup WebRTC media engine**.

Built as an independent SaaS product that can be sold directly to educators, coaching institutes, schools, and enterprise teams.

---

## 🚀 Quick Start

From your terminal:

```bash
cd /Users/adityachavhan/Documents/Mathsy/mathsy-meet

# Start local development server (runs on http://localhost:5174)
npm run dev

# Or build for production
npm run build
```

## 🌟 Core Superpowers & Features

1. **Google Meet Familiar UI/UX**:
   - Clean dark/light theme with Google Sans typography.
   - Dynamic adaptive video grid (spotlight, active speaker glow, tile pinning).
   - Bottom floating pill control bar (Mic, Camera, Screen Share, Whiteboard, Reactions, Hand Raise, Drawers).

2. **Self-Hosted Mediasoup SFU (`https://rtc.mathsy.in`)**:
   - Broadcast-quality, 50ms ultra-low latency audio & video streaming.
   - Zero per-minute cloud costs.
   - Scale to hundreds of concurrent participants.

3. **STEM & Math Geometry Whiteboard**:
   - Embedded collaborative TLDraw infinite canvas.
   - **Ruler Tool**: Real-world cm markings and angle measurement.
   - **Compass Tool**: Draw accurate circles and arcs.
   - **Protractor Tool**: 180° / 360° angle measurements.
   - **Set Square Tool**: Precise triangular drafting.
   - Clear canvas, shapes, colors, undo/redo.

4. **In-Meeting Interactive Activities & Polls**:
   - Host can publish single-choice and multiple-choice polls in real-time.
   - Instant graphical bar chart vote visualizers.

5. **Floating Emoji Reactions**:
   - Smooth physics-based floating reactions (❤️, 👍, 👏, 🎉, 🚀, 😂) across the screen.

6. **Screen Sharing & HD Recording**:
   - Native display & tab audio presentation.
   - Local browser recording directly to MP4/WebM.
   - Direct RTMP YouTube Live streaming support.

7. **Google Auth & Guest Lobby**:
   - Google Sign-In with 1 click.
   - Pre-join meeting lobby with camera test, mic volume meter, and name input.
   - Shareable room links (`http://localhost:5174/meet/xxx-yyyy-zzz`).

8. **Commercial SaaS Landing Page & Pricing Plans**:
   - **Free Starter Plan** ($0/mo)
   - **Pro Educator Plan** ($15/mo or ₹999/mo)
   - **Academy & Enterprise Plan** ($49/mo or ₹3,499/mo)
